## Download and run
- `batman_cobblebot_native.exe` — standalone native Windows x64 game executable from the pinned successful CI artifact.
- `Batman-CobbleBot-Level1A-Windows-x64.zip` — packaged EXE + `LICENSE`, `THIRD_PARTY_NOTICE.md` and these notes. Extract and run the EXE; no Flash, Python or Rust installation is required to play.
- `SHA256SUMS.txt` — SHA-256 digests of both distributed EXE and ZIP. Check locally with PowerShell `Get-FileHash -Algorithm SHA256 .\batman_cobblebot_native.exe`.
- **Source code.zip / .tar.gz** — automatically generated by GitHub from the same version tag pointing to the exact verified source commit. The source archive includes Rust game code and source-reconstruction/build tooling, not a separately committed proprietary SWF.

## Features in this Level1A snapshot
Reconstructed 600×400/25 Hz game logic with high-quality 3× presentation, original-game-derived story intro, source SKIP mouse/keyboard controls and fade, redesigned/iteratively tested HUD positioning, level gameplay, native F/Esc fullscreen, focus-aware intro playback and source-derived embedded Windows taskbar icon. Deterministic headless smoke and Windows GUI tests are in the repository.

## Limits and known risks
GitHub-hosted Windows could not verify physical speakers (MCI error 277 / no audio output endpoint). No exhaustive original Flash side-by-side, pinned user taskbar cache, all DPI monitors, or comprehensive formal Rust security audit has been certified. User's current-game approval is narrower than those checks. Source quality review tracks medium-risk audio temp-dir collisions/cleanup and raw Win32 pointer ownership/early-error cleanup plus lower-severity parser/dev CLI and build-supply-chain improvements. **These are documented, not represented as fixed.** See [release quality report](https://github.com/sinethnimsara26/Batman-CobbleBot-Native-Rust/blob/revive/level1a-intro-hud-fidelity-2026-11-09/docs/releases/LEVEL1A_V0.2.0_RELEASE_QUALITY.md). Strict remaining fidelity issue [#17](https://github.com/sinethnimsara26/Batman-CobbleBot-Native-Rust/issues/17) stays open; draft PR [#18](https://github.com/sinethnimsara26/Batman-CobbleBot-Native-Rust/pull/18) unmerged. Main and Level1B branches are untouched.
